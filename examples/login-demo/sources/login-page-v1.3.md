# 账号登录评审工作台 v1.3 增量需求

- 父版本：v1.2
- 页面：账号登录
- 范围：登录中心品牌、左侧信息交互与视觉主题；不改变认证接口或表单规则

## 需求原文

1. 将当前登录中心左侧顶部的“北辰工作台”去掉，替换为“测试工作台”。
2. 优化登录页面左侧区域交互，解决当前展示过于简陋的问题。
3. 登录页面主题改为蓝色主题。

## 设计约束

- 左侧交互只展示测试环境信息，不增加真实业务入口或网络请求。
- 展开 / 收起控件必须支持鼠标与键盘操作，并暴露正确的可访问状态。
- 桌面和移动宽度下，品牌信息、交互控件与登录表单不得重叠或产生页面级横向滚动。

## 验收

1. 页面标题、左侧品牌名及登录成功提示中的工作区名称均使用“测试工作台 / 测试工作区”语义，不再出现“北辰工作台”。
2. 左侧可通过“查看测试环境信息”展开和收起环境说明，按钮状态与内容可见性同步，Enter / Space 均可操作。
3. 登录页使用蓝色品牌色及对应浅色焦点、状态反馈，原有表单校验、密码显隐、记住账号和登录状态不回归。
4. 1280px 与 390px 宽度下页面内容保持清晰、可操作且无横向溢出。
