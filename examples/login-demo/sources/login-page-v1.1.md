# 账号登录评审工作台 v1.1 增量需求

- 父版本：v1.0
- 页面：账号登录
- 范围：设计评审工作台，不改变登录业务表单

## 需求原文

1. 登录页形成 v1.1 子版本 Markdown，保留 v1.0 且建立父子关系。
2. 工作台针对每个页面提供版本选择，可以在线预览所选版本的开发 Markdown。
3. 切换版本后，下载内容和文件名必须对应当前选择，不能仍下载最新版本。
4. 每个版本展示自己的基线提交、实现提交和 MR/PR；具备提交范围时提供稳定的 Diff 入口。
5. v1.0 未关联 MR 时明确显示“未关联”，不得伪造编号或链接。

## 验收

1. 账号登录的开发规格页能在 v1.0 与 v1.1 之间切换，并显示对应版本标题与正文。
2. 默认选择当前发布版本 v1.1。
3. v1.0 和 v1.1 的下载文件名、内容分别匹配所选版本。
4. 所选版本的 MR 和 Diff 信息与该版本 `trace.json` 一致。
5. 桌面与 390px 移动宽度下版本工具栏、文档正文和操作按钮不重叠。
