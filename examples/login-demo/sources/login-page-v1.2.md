# 账号登录评审工作台 v1.2 增量需求

来源：用户确认需要避免完整快照在每次评审时重复展示，要求实现“本版变更 / 完整规格”双视图。

## 需求

1. 每个已发布版本同时提供本版变更和完整规格两个开发文档视图。
2. 初次进入开发规格时默认展示当前版本的本版变更。
3. 切换文档视图时，版本追溯信息保持不变，Markdown 正文和下载目标同步切换。
4. 切换版本时保留当前选择的文档视图，避免连续对比时重复操作。
5. 下载文件名必须同时包含页面、版本和视图类型，不能把增量文档误标为完整规格。
6. 双视图内容继续内嵌在单文件工作台中，不发起网络请求。

## 验收

1. 默认打开 v1.2 时显示 `change-dev.md` 的正文。
2. 点击“完整规格”后显示 `snapshot-dev.md`，下载按钮同步指向完整规格。
3. 在完整规格视图切换 v1.2、v1.1、v1.0 时保持完整规格视图；切回本版变更后同理。
4. 桌面和 390px 宽度下，版本选择、双视图控件、下载按钮和 Markdown 正文无重叠。
