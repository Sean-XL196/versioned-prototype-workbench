# 账号登录页需求

- 产品版本：v1.0
- 页面：账号登录
- 性质：交互评审原型，不连接真实认证服务

## 目标

为内部业务系统提供清晰、可信且可在桌面和移动端使用的账号登录入口。

## 页面内容

- 产品名称与简洁品牌识别。
- 账号输入框，支持输入用户名。
- 密码输入框，支持显示或隐藏密码。
- “记住账号”复选框。
- “忘记密码”入口。
- 主按钮“登录”。

## 交互

- 初始焦点落在账号输入框。
- 账号或密码为空时，在对应字段附近显示错误，不清空用户输入。
- 提交时登录按钮进入加载和禁用状态，避免重复提交。
- 演示账号为 `demo-admin`，演示密码为 `Demo@123`。
- 凭据错误时显示明确错误，并保留账号。
- 登录成功时显示成功反馈和目标工作区名称；原型不执行真实跳转。
- 勾选“记住账号”后，刷新页面仍回显账号；不保存密码。
- “忘记密码”只展示原型说明，不调用外部服务。

## 验收

1. 桌面宽度 1280px 和移动宽度 390px 下无内容重叠或页面级横向滚动。
2. 支持键盘 Tab 顺序和 Enter 提交，焦点样式清晰。
3. 空账号、空密码、错误凭据和成功凭据均有独立可见结果。
4. 密码显隐按钮具备可访问名称，切换不丢失输入。
5. 连续点击登录只触发一次提交过程。
