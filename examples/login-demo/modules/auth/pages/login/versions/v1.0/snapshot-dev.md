# 账号登录 - 开发规格

> 当前完整有效规格。版本：v1.0

## 1. 目标与范围

为内部业务系统提供独立、可评审的账号登录页面。页面只模拟认证交互，不连接真实后端，不代表生产安全实现。

## 2. 来源与基线

| ID | 来源 | 结论 |
| --- | --- | --- |
| SRC-001 | `sources/login-page.md` | 本版本需求与验收的唯一输入。 |

本页面是全新设计，没有可核验的既有页面或 As-Is 基线。

## 3. 页面需求

| ID | 需求 | 证据 | 原型定位 |
| --- | --- | --- | --- |
| REQ-001 | 显示产品名称、登录标题和安全环境提示；桌面与移动端均保持清晰层级。 | SRC-001 | `.login-brand`、`.login-panel` |
| REQ-002 | 提供账号输入框并在页面打开时获得焦点。 | SRC-001 | `#username` |
| REQ-003 | 提供密码输入框以及带可访问名称的密码显隐按钮。 | SRC-001 | `#password`、`#toggle-password` |
| REQ-004 | 提供“记住账号”复选框和“忘记密码”入口，只保存账号、不保存密码。 | SRC-001 | `#remember`、`#forgot-password` |

## 4. 交互与规则

| ID | 类型 | 规则 | 失败行为 |
| --- | --- | --- | --- |
| INT-001 | 登录提交 | 点击登录或按 Enter 后进入提交中状态；按钮禁用且只处理一次；完成后恢复。 | 保留账号输入并显示明确错误。 |
| INT-002 | 密码显隐 | 点击图标在 password/text 类型之间切换，更新按钮可访问名称，不移动焦点。 | 输入内容不得丢失。 |
| INT-003 | 辅助操作 | 勾选记住账号后刷新仍回显账号；忘记密码只显示原型说明。 | 不发起外部请求，不保存密码。 |
| RULE-001 | 必填校验 | 账号和密码均必填；错误信息与字段关联，首次错误字段获得焦点。 | 表单保持原值。 |
| RULE-002 | 演示认证 | 仅 `demo-admin / Demo@123` 返回成功，其余组合返回“账号或密码错误”。 | 不泄露具体哪个字段不匹配。 |

## 5. 状态

- 初始：表单可编辑，登录按钮可用。
- 校验失败：字段显示错误，页面提示区同步反馈。
- 提交中：按钮显示“登录中”，全部提交入口禁用。
- 认证失败：保留账号，清空密码并聚焦密码框。
- 认证成功：显示“验证通过，正在进入演示工作区”，原型不真实跳转。

## 6. 验收标准

- [ ] TST-001 验证初始内容、焦点和键盘顺序。
- [ ] TST-002 验证空账号与空密码的 RULE-001。
- [ ] TST-003 验证错误凭据的 RULE-002。
- [ ] TST-004 验证成功凭据和 INT-001 防重复提交。
- [ ] TST-005 验证密码显隐、记住账号和忘记密码说明。
- [ ] TST-006 验证 1280px 与 390px 布局无重叠和页面级横向滚动。

## 7. 非目标

不实现注册、验证码、单点登录、真实密码找回、真实网络请求、Token 存储或权限跳转。
