## 5. 对核心流程的影响

登录提交、必填校验、密码显隐、记住账号和忘记密码流程保持不变。进入页面后，用户可在左侧查看测试环境信息；展开状态只影响左侧展示，不改变账号表单状态，也不发起网络请求。品牌色调整仅影响展示层 token 和左侧背景。
