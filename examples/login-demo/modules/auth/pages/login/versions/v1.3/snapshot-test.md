# 账号登录 - 测试规格

> 当前完整有效测试规格。版本：v1.3

## 1. 前置条件

登录交互使用构建后的 `dist/auth/login.html`；版本化文档预览使用 `dist/index.html#auth%2Flogin`。清除登录页 localStorage 后执行首轮测试。

## 2. 核心用例

| --- | --- | --- | --- |

## 3. 回归检查

- [ ] 浏览器控制台无未处理异常。
- [ ] 登录成功和失败均不会产生真实网络请求。
- [ ] 页面刷新后密码字段始终为空。
- [ ] 颜色不是状态信息的唯一表达方式。
- [ ] 工作台切换版本不发起网络请求，直接打开本地 HTML 仍可使用。
- [ ] 未选择的版本文档不会同时暴露在可见区域。
- [ ] 同一版本中未选择的文档视图不会同时暴露在可见区域。
