# 账号登录 - 开发规格

> 当前完整有效规格。版本：v1.3

## 1. 目标与范围

为内部业务系统提供独立、可评审的账号登录页面。页面只模拟认证交互，不连接真实后端，不代表生产安全实现。

## 4. 交互与规则

| ID | 类型 | 规则 | 失败行为 |
| --- | --- | --- | --- |
| INT-001 | 登录提交 | 点击登录或按 Enter 后进入提交中状态；按钮禁用且只处理一次；完成后恢复。 | 保留账号输入并显示明确错误。 |
| INT-002 | 密码显隐 | 点击图标在 password/text 类型之间切换，更新按钮可访问名称，不移动焦点。 | 输入内容不得丢失。 |
| INT-003 | 辅助操作 | 勾选记住账号后刷新仍回显账号；忘记密码只显示原型说明。 | 不发起外部请求，不保存密码。 |
| INT-004 | 版本化开发文档预览 | 切换版本时仅展示该版本的完整开发快照，并同步更新下载文件名、版本追溯和 Diff 入口。 | 所选版本缺少 MR 时明确显示“未关联 MR”，不隐藏文档。 |
| INT-005 | 开发文档双视图 | 初次进入默认本版变更；切换视图只替换所选版本的 Markdown 与下载目标；切换版本时保留当前视图。 | 不允许正文、下载文案、文件名或追溯信息出现跨版本、跨视图错配。 |
| INT-006 | 左侧环境信息 | 点击“查看测试环境信息”切换详情区域；按钮同步 `aria-expanded`，详情同步 `hidden`；Enter / Space 可操作。 | 详情状态不更新或影响表单时视为失败。 |
| RULE-001 | 必填校验 | 账号和密码均必填；错误信息与字段关联，首次错误字段获得焦点。 | 表单保持原值。 |
| RULE-002 | 演示认证 | 仅 `demo-admin / Demo@123` 返回成功，其余组合返回“账号或密码错误”。 | 不泄露具体哪个字段不匹配。 |
| RULE-003 | 可预览版本范围 | 只列出当前发布链中的已发布版本，按版本链顺序排列，默认选中 `current.released`。 | 不展示草稿或脱离当前链的历史节点。 |
| RULE-004 | 文档视图来源 | “本版变更”读取该版本 `change-dev.md`；“完整规格”读取 `snapshot-dev.md`；两者构建时离线内嵌。 | 不通过运行时网络请求读取 Markdown，不把增量文件标记为完整规格。 |
| RULE-005 | 蓝色主题 | 品牌背景、主按钮、焦点环和信息状态使用蓝色及浅色配套；状态不能只依赖颜色表达。 | 对比度不足、仍显示旧绿色主视觉或出现横向溢出时视为失败。 |

## 5. 状态

- 初始：表单可编辑，登录按钮可用。
- 校验失败：字段显示错误，页面提示区同步反馈。
- 提交中：按钮显示“登录中”，全部提交入口禁用。
- 认证失败：保留账号，清空密码并聚焦密码框。
- 认证成功：显示“验证通过，正在进入测试工作区”，原型不真实跳转。
- 左侧环境信息：默认收起；点击或键盘操作后展开测试环境、认证方式和数据范围，再次操作恢复收起。
- 规格预览：默认显示 v1.3 的本版变更；可切换 v1.0/v1.1/v1.2/v1.3 与本版变更/完整规格，文档、下载与追溯信息保持同一版本和视图。

## 7. 非目标

不实现注册、验证码、单点登录、真实密码找回、真实网络请求、Token 存储或权限跳转。本版本不改变登录业务表单；左侧环境详情不增加真实业务入口。工作台不负责创建或合并 MR，也不在浏览器运行时读取外部 Markdown。
