# 服务请求 - 开发规格

> 当前完整有效规格。版本：v1.2

## 1. 目标与范围

提供可独立评审的服务请求列表，并包含明确的成功与拒绝示例。

## 2. 当前基线与证据

这是原型的初始基线，不代表任何生产系统。

## 3. 需求

| ID | 需求 | 证据 | 影响范围 |
| --- | --- | --- | --- |
| REQ-001 | 显示请求编号、状态与金额。 | 初始演示需求 | 界面与样例数据 |
| REQ-002 | 在请求编号下方显示优先级，不新增表格列。 | 示例客户反馈 | 界面与样例数据 |
| REQ-003 | 提供汇总指标、可搜索和筛选的记录、CSV 导出及响应式运营布局。 | SRC-003 / CHG-002 | 共享设计模板与页面交互 |

## 4. 交互与规则

| ID | 类型 | 规则 | 失败行为 |
| --- | --- | --- | --- |
| INT-001 | 交互 | 主要操作通过页面提示区反馈执行结果。 | 页面不跳转。 |
| RULE-001 | 规则 | 任何已阻塞记录都会阻止操作成功完成。 | 显示拒绝提示。 |
| INT-002 | 交互 | 搜索与状态筛选会更新结果集；重置恢复全部记录；导出下载当前筛选结果。 | 没有匹配记录时显示稳定的空状态。 |

## 5. 当前有效用户流程

1. 查看请求记录及其优先级。
2. 执行主要操作。
3. 查看已阻塞样例触发的拒绝提示。
4. 筛选或搜索记录，并重置结果集。

## 6. 依赖与契约

无需跨页面依赖。

## 7. 验收标准

- [ ] 请求表格显示三条样例数据。
- [ ] 每条记录在不增加表格列的前提下显示优先级。
- [ ] 已阻塞样例会触发拒绝提示。
- [ ] TST-004 在桌面和移动端宽度验证 REQ-003 与 INT-002。
